About this speed test

The test transfers data between your browser and the test server. Results reflect your device, Wi-Fi or wired connection, router, provider and route to that server. They’re an estimate, not a guarantee of your plan’s maximum speed.

For a useful result

  1. Pause downloads, backups and streams on other devices.
  2. Run the test near your router; compare with Ethernet if possible.
  3. Run it more than once. Results can vary with traffic and server conditions.

What the numbers mean

Download is how quickly data reaches your device. Upload is how quickly it sends data. Latency is the round-trip response time in milliseconds; lower is usually better for calls and gaming. Jitter estimates how much latency varies. Failed probes are HTTP test requests that did not complete—they are not an IP packet-loss measurement.

Latency under load compares response time while data is moving with idle latency. It’s a rough indication only, not a formal bufferbloat grade.

FAQ

Is this speed test accurate?

It provides a practical estimate from this browser to the test server. Wi-Fi conditions, device performance, background traffic and server routing all affect results.

How much data does a test use?

The test transfers real data, and faster connections may transfer more. Avoid repeated tests on a limited mobile-data plan.

Does this measure packet loss?

No. Failed probes count incomplete HTTP latency requests; they are not a direct IP-level packet-loss test.
