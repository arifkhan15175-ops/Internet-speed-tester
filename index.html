About the SparkNoa internet speed test

SparkNoa estimates your connection's download and upload throughput by transferring data through its configured Cloudflare Worker endpoints. Latency is measured using HTTP requests from your browser, so results include server, routing, browser, and connection effects.

How to get a more useful result

  • Pause large downloads, cloud backups, and streaming on other devices before testing.
  • For a Wi-Fi check, test near the router; compare with Ethernet if available.
  • Run the test more than once at different times. A single result is a snapshot, not a guaranteed speed.
  • Use the activity labels as rough guidance. Real streaming, gaming, and video-call quality also depend on the service, Wi-Fi quality, congestion, and other devices.

What do the measurements mean?

Download and upload: approximate data throughput during this test. Idle latency: round-trip time for HTTP probes to the test endpoint. Jitter estimate: average absolute change between consecutive successful latency samples. Failed probes: the percentage of HTTP latency probes that failed; this is not true IP packet loss. Latency under load: a rough comparison of latency while the test transfers data against idle latency, not a certified bufferbloat benchmark.
